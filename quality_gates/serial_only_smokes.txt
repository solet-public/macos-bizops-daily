# Serial-only smoke schedule -- the ONE source of truth for which registered
# smokes hold a HOST-EXCLUSIVE resource for their whole run and therefore
# cannot share the host with ANY concurrently-running smoke.
#
# Consumed by BOTH schedulers that run the register: quality_gates/run_smokes.py
# (the checkout battery, which reads this file next to itself) and the born-clone
# publication gate in seed_factory_plugin (which reads the copy shipped inside
# the bundle under verification, alongside the register it runs). Until
# 2026-09-20 each carried its own hand-maintained list and the two diverged
# twice (iss_f939bae7; first divergence root-caused as the r17/r20 born-clone
# gate red, iss_169b1b80). A regression smoke fails when the two readers can be
# made to disagree.
#
# Grammar is the register's: one repo-relative smoke path per line, `#` starts a
# comment. An entry names the specific resource MEASURED, not a guess. An entry
# absent from the register being run is inert. Members are run one at a time
# before the worker pool starts; run_smokes.py additionally host-serializes that
# phase across separate batteries (iss_0fb8f519). The same contention class is
# filed cross-lane as GTE-16/GTE-17; when those land as per-run-unique
# resources, the corresponding entry can be removed.

# Shells out to REAL `pip install -e` / `pip uninstall` against the shared repo
# venv three times per run -- rewrites the __editable__ .pth site configuration
# every pooled smoke's freshly-spawned interpreter would be reading mid-flight.
ananta/tests/lifecycle_management_service/set_plugin_enabled_reenable_smoke.py

# smoke mocks brew or builds a fixture Cellar). Under run_smokes.py's pooled
