# Sub-2 additions (W-VAULT-CALLER-ENFORCE, 2026-06-07):
#
# - Per-plugin token_store.py modules and direct callers use f-string-built
#   scoped vault-key constants (e.g. ``f"{_SOLET}.<plugin>.<credential>"``)
#   at the module-level Final[str] declaration. The static-gate's
#   constant-resolution pass (Codex correction #5) only evaluates pure
#   literal Final[str] constants — f-strings are deliberately out of scope
#   because they require executing module-level code to materialize the
#   value. Coordinator-Dawn release framing (2026-06-07 PT):
#   "dynamic-helper construction is namespace-safe at runtime" — the
#   runtime ``enforce_namespace`` call on the resolved key still catches
#   any cross-namespace violation; the static gate just can't pre-verify
#   the f-string-built key matches the plugin's declared prefix.
#
#   Tracked-debt remediation: either replace the f-string constant with
#   a runtime-init Final[str] literal once SOLET_NAME is bound, OR
#   add per-line ``# vault-key: <declared-prefix>`` annotations so the
#   gate's annotation pass accepts them. Both routes remove an entry
#   from this allowlist.
